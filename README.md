# Akshara-Deepa Tutor

Akshara-Deepa Tutor is an intelligent, offline-first Android study companion designed specifically for 10th-grade SSLC students. Built with modern Android development practices, it provides an adaptive, engaging, and accessible learning experience to help students master their syllabus.

## Features

*   **Intelligent SSLC Quiz System:** Adaptive, non-repeating quizzes dynamically pulled from a robust local question bank to test knowledge effectively.
*   **Performance Tracking:** Tracks student performance metrics, best scores, and attempts, helping to identify and address knowledge gaps.
*   **Daily Learning Tips:** Engaging and educational daily motivational study tips to keep students inspired.
*   **Syllabus Tracker:** A structured way to monitor chapter mastery and overall learning progress.
*   **Offline-First:** Fully functional without an internet connection, ensuring accessibility anytime, anywhere.
*   **Modern UI:** Built entirely with Jetpack Compose following Material 3 design guidelines for a seamless, high-performance user experience.

## Tech Stack

*   **Language:** Kotlin
*   **UI Toolkit:** Jetpack Compose (Material 3)
*   **Architecture:** MVVM (Model-View-ViewModel)
*   **Local Storage:** Room Database

## Getting Started

To build and run the project locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/AksharaDeepaTutor.git
    ```
2.  Open the project in **Android Studio**.
3.  Allow Android Studio to sync the project with Gradle files.
4.  Run the app on an Android Emulator or a physical device.
